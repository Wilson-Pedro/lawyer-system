Dicionário de Erros da API

Esta página documenta os erros que podem ser retornados pela API e como resolvê-los.

Dados Inválidos

HTTP 400 Bad Request

O que significa: O corpo da requisição possui campos inválidos, em branco ou fora do padrão esperado.

Como resolver: Verifique a lista fields retornada na resposta para identificar quais campos falharam e corrija-os.

Violação de Regra de Negócio

HTTP 400 Bad Request

O que significa: A requisição é válida estruturalmente, mas a ação solicitada fere alguma regra de negócio da aplicação.

Como resolver: Leia a mensagem no campo detail para entender o motivo do bloqueio e ajuste a operação de acordo.

Violação de Integridade

HTTP 400 Bad Request

O que significa: A operação tentou referenciar um ID que não existe no banco de dados ou tentou excluir um registro que possui vínculos importantes.

Como resolver: Verifique se os IDs passados (ex: IDs de chaves estrangeiras) estão corretos e existem na base de dados.

Não Autenticado (Token Inválido)

HTTP 401 Unauthorized

O que significa: A requisição não enviou o cabeçalho Authorization: Bearer {token}, ou o token enviado expirou/é inválido.

Como resolver: Faça login novamente na rota /auth/login para obter um novo token JWT e envie-o no cabeçalho da requisição.

Credenciais Inválidas

HTTP 401 Unauthorized

O que significa: O e-mail ou a senha fornecidos durante a tentativa de login estão incorretos.

Como resolver: Verifique se os dados de acesso foram digitados corretamente e tente novamente.

Acesso Negado

HTTP 403 Forbidden

O que significa: O seu token é válido, mas o seu perfil (Role) não tem permissão para acessar este recurso. Exemplo: Um estagiário tentando acessar uma rota exclusiva de administrador.

Como resolver: Contate um administrador do sistema para revisar suas permissões.

Conta Bloqueada

HTTP 403 Forbidden

O que significa: A conta de usuário está temporariamente suspensa ou em período de férias, impedindo o acesso ao sistema.

Como resolver: Aguarde o término do período de bloqueio ou contate a administração.

Conta Inativa

HTTP 403 Forbidden

O que significa: A conta de usuário foi desativada ou excluída pelo administrador.

Como resolver: Entre em contato com a administração para solicitar a reativação da conta.

Recurso Não Encontrado

HTTP 404 Not Found

O que significa: O registro, usuário ou recurso solicitado na URL não existe no sistema.

Como resolver: Verifique se o ID ou parâmetro passado na URL está correto.

Conflito de Dados

HTTP 409 Conflict

O que significa: Você tentou cadastrar um dado que já existe no banco de dados e deve ser único (como uma Matrícula ou E-mail).

Como resolver: Verifique se o usuário já possui cadastro ou utilize dados diferentes na requisição.

Erro Interno do Servidor

HTTP 500 Internal Server Error

O que significa: Ocorreu uma falha inesperada no servidor durante o processamento da sua requisição.

Como resolver: Tente novamente mais tarde. Se o erro persistir, acione o suporte técnico informando a hora exata da falha e a ação que tentou realizar.
